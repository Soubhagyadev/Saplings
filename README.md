# Saplings

An AI study tool that turns notes and lecture PDFs into a navigable topic tree and source-grounded flashcards.

## Stack

React, TypeScript, and Vite.

## Structure

```text
src/
  app/          # App shell and routing
  components/   # Reusable UI (tree, flashcards, layout)
  features/     # Import, topic exploration, study flows
  hooks/         # Shared React hooks
  lib/           # Utilities and constants
  services/      # API/PDF/AI integrations
  store/         # Client state
  types/         # Shared TypeScript types
```
